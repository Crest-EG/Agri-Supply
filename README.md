# Crest Supply Tracker

تطبيق داخلي عربي باتجاه RTL لمتابعة رحلات التوريد الزراعي من المورد إلى المصنع، مع إدارة البيانات والمستخدمين، الصور، العمل دون اتصال، وملخص محاسبي للمدير.

## المتطلبات

- Node.js بإصدار يدعم `--experimental-strip-types`، ويفضل Node.js 22.6 أو أحدث.
- مشروع Supabase متصل بالتطبيق.
- ملفا المرجع في جذر المشروع: [`001_schema.sql`](./001_schema.sql) و[`002_agent_plan.md`](./002_agent_plan.md).

## تشغيل محلي

1. انسخ `.env.example` إلى `.env.local` وأضف بيانات مشروع Supabase:

   ```dotenv
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
   SUPABASE_SERVICE_ROLE_KEY=server-only-service-role-key
   ```

   `SUPABASE_SERVICE_ROLE_KEY` مطلوب لإنشاء المستخدم الإداري وإدارة حسابات المستخدمين، ويظل على الخادم. لا تضعه تحت متغير يبدأ بـ `NEXT_PUBLIC_`.

2. طبّق `001_schema.sql` في Supabase إذا لم يكن مطبقًا بالفعل. ينشئ المخطط الجداول والعروض وسياسات RLS ومساحة التخزين الخاصة `trip-photos`. لا تعِد تشغيله على قاعدة بيانات جاهزة إلا بعد مراجعة أثره.

3. ثبّت الحزم وشغّل التطبيق:

   ```sh
   npm install
   npm run dev
   ```

4. أنشئ المدير الأول من الطرفية. سيطلب الأمر الاسم ورقم الهاتف المصري وكلمة مرور مؤقتة من 10 أحرف على الأقل:

   ```sh
   npm run seed:admin
   ```

   يحتاج هذا الأمر إلى `NEXT_PUBLIC_SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` في `.env.local`. يسجل الدخول برقم الهاتف، ويُطبّع الرقم المصري إلى صيغة `20…` ويطابقه مع بريد داخلي ينتهي بـ `@crest.local`.

## الصفحات والوظائف

- `/trips`: قائمة الحركات والفلاتر والترقيم؛ المدير يرى كل الحركات ويمكنه التصفية حسب المهندس.
- `/trips/new` و`/trips/[id]`: إنشاء الحركات وتعديلها، تدفق الحالات، قفل تعديل المهندس بعد اعتماد المصنع، وتحميل صورة الرحلة.
- `/suppliers`: عرض الموردين وتحريرهم وربطهم بالمنتجات.
- `/admin/products`: المنتجات والأسعار اليومية.
- `/admin/factories`: المصانع والمنتجات التي تستقبلها.
- `/admin/users`: إنشاء حسابات المهندسين وإعادة تعيين كلمات المرور وإيقاف الحسابات.
- `/admin/settings`: نسبة العمولة الافتراضية للرحلات الجديدة.
- `/admin/accounting`: ملخص محاسبي وتصدير CSV. تُحسب المجاميع النهائية من الحركات ذات حالة `analysis_accepted` فقط.

التطبيق يدعم التثبيت كـ PWA، ويحفظ بيانات الحركات للعمل دون اتصال ثم يزامن التغييرات عند عودة الشبكة. الصور تُضغط على الجهاز وتُرفع إلى مخزن خاص، ويُعرض رابط مؤقت للصورة الكاملة عند فتحها.

## أوامر التحقق

```sh
npm run lint
npm run build
```

## قواعد الأمان

- سياسات RLS في Supabase هي مرجع الصلاحيات. فحوص الواجهة والخادم لا تستبدلها.
- مفتاح الخدمة للاستخدام الخادمي فقط، ويُستخدم لإدارة المستخدمين دون كشفه للمتصفح.
- بيانات الصور محفوظة في bucket خاص، ولا تُخزّن استجابات API الموثقة في Service Worker.
- بيانات الرحلة المالية المشتقة تأتي من الأعمدة المولدة في قاعدة البيانات.

## الهوية والتصميم

واجهة عربية RTL وأرقام لاتينية. رموز الألوان معرفة في `src/app/globals.css`، وتستخدم الصفحات فئات Tailwind المنطقية مثل `ps-*` و`pe-*`. لون النص الأبيض محصور بالأزرار الخضراء الداكنة؛ نصوص CTA البرتقالية خضراء داكنة.
